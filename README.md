# 경충FC 클럽하우스

경충FC 회원을 위한 웹 클럽하우스입니다. 회원 목록, 회비 현황, 공지사항, 주말 풋살 일정과 참석 여부, 용병 명단, 팀 편성, 커피 내기 경기 기록, MOM 투표, 활동 랭킹, 사용자 의견, 투표·설문·회장단 선거를 한곳에서 제공합니다.

사용자 의견은 작성자 식별 정보와 함께 Supabase 내부 데이터베이스에 저장됩니다. 시스템 제보는 제출 화면에서 공개될 제목·본문·제보자 표시를 미리 확인하고 별도 공개 동의 체크박스를 선택한 경우에만 `jaywapp/gyungchung`의 공개 GitHub Issue로 중계됩니다. 익명을 선택하면 공개 이슈에는 제보자가 `익명`으로 표시되고, 선택하지 않으면 회원 이름이 공개됩니다. 다른 분류와 공개에 동의하지 않은 시스템 제보는 운영진 게시판에만 저장됩니다. GitHub 생성에 실패해도 원본 제보는 `접수` 상태로 유지되며, 접수 내역에서 공개 실패 상태와 재시도 안내를 확인할 수 있습니다. 이미 공개된 기존 이슈는 그대로 유지합니다.

GitHub 중계를 사용하려면 Issues 쓰기 권한만 가진 최소 권한 토큰을 Supabase Function secret `GITHUB_ISSUES_TOKEN`으로 등록해야 합니다.

회원 유형은 `manager`, `member`로 구분됩니다. `manager`는 회장·부회장·총무 직책에 따라 운영 업무를 담당하고, `member`는 일반 회원 기능을 사용합니다. 시스템 관리 권한은 회원 유형과 별도로 부여되는 특별권한이므로 일반회원이나 관리자 모두 가질 수 있으며, 회비는 시스템 권한이 아닌 기본 회원 유형과 회비 방식에 따라 부과됩니다.

## 로컬 실행

1. `.env.example`을 `.env.local`로 복사하고 Supabase 공개 연결 정보를 입력합니다.
2. `npm install`
3. `npm run dev`

## 데이터베이스

`supabase/migrations`의 마이그레이션은 회원·회비·공지·일정·실제 출석·용병·팀 편성·경기 기록·MOM·의견·투표·설문·선거 테이블, 역할별 권한과 RLS 정책을 생성합니다. 경충FC는 관리자 프로비저닝 모델을 사용합니다. 운영진이 회원 명단과 전화번호 기반 로그인 계정을 등록하고, 회원은 안내받은 전화번호와 초기 비밀번호로 로그인합니다. 공개 회원가입, 가입 신청, 거절, 재신청 화면은 제공하지 않습니다. 신규 가입을 원하거나 계정 연결이 필요한 경우 운영진에게 이름과 전화번호를 알려 등록을 요청해야 합니다. 등록 후 승인 대기 계정은 참석 등록·참여 응답·의견 작성·활동 랭킹을 이용할 수 없으며, 승인 상태는 운영진에게 문의합니다. 활동이 중단된 계정도 같은 기능이 제한되며, 활동 재개는 운영진이 처리합니다. 카카오·Google 로그인은 마이페이지에서 기존 회원 계정에 연결한 경우에만 사용할 수 있습니다.

활동 랭킹은 실제 출석 1회당 3점, 회비 납부 1개월당 1점으로 계산합니다. MOM은 일정 시작 후 실제 출석 회원끼리 본인을 제외하고 1인 1표로 투표하며, 일정별 상위 1~3위와 누적 기록을 제공합니다. 커피 내기 모드는 금전 정산이 아니라 팀 스코어·승패·개인 골·평점을 기록하는 경기 모드입니다.

## 인증 설정

Supabase Authentication Providers에서 Email, Google과 Kakao를 활성화하고, 배포 주소의 `/auth/callback`을 Redirect URLs 허용 목록에 추가합니다. 이메일 인증과 자동 identity linking을 사용하며, 회원의 권한은 `profiles`에서만 관리합니다. Kakao Developers와 Google Cloud에는 Supabase가 표시하는 provider callback URL을 등록합니다. Kakao 앱은 Biz App으로 전환한 뒤 동의 항목의 `account_email`, `profile_nickname`, `profile_image`를 활성화합니다. 이메일 없는 계정 허용 옵션을 사용하더라도 앱에서 별도 이메일 인증을 요구합니다.

## 배포

Vercel Git Integration을 통해 `main` 브랜치의 변경 사항이 프로덕션에 자동 배포됩니다.
