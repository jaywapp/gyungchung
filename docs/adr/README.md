# 아키텍처 결정 기록 (ADR)

되돌리기 비싼 구조 결정과, **의도적으로 지금 하지 않기로 한 결정**을 남긴다.
"왜 안 고쳤나"를 나중에 다시 묻지 않기 위한 기록이므로, 재검토 트리거를 수치로 함께 적는다.

| 번호 | 제목 | 상태 | 날짜 |
|---|---|---|---|
| [0001](./0001-clubhouse-client-data-loading.md) | 클럽하우스 클라이언트 일괄 데이터 로딩을 당분간 유지한다 | 승인 | 2026-08-22 |

## 작성 규칙

- 파일명은 `NNNN-영문-슬러그.md`, 본문은 한국어.
- 맥락 → 검토한 선택지와 비용 → 결정과 근거 → 받아들이는 비용 → 재검토 트리거 → 착수 시 계획 순서로 쓴다.
- 결정을 바꾸면 기존 문서를 고치지 말고 새 ADR을 추가한 뒤, 이전 문서의 상태를 `대체됨 (ADR-NNNN)`으로 바꾼다.
- 새 ADR을 추가하면 위 목록도 함께 갱신한다.
