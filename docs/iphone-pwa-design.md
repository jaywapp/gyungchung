# iPhone 홈 화면 앱 설계

## 화면 방향

기존 경충FC 회원용 설치·계정 안내로 해석한다. 승인된 구단 소개형의 남색, 녹색, 라임색과 Pretendard, 기존 버튼·모달·테마 토큰을 유지한다. `DESIGN_VARIANCE=3`, `MOTION_INTENSITY=2`, `VISUAL_DENSITY=5`로 설정하고 설치와 권한 상태를 짧게 설명한다. design-taste-frontend의 마케팅 장식은 계정 설정에 적용하지 않는다.

## 구성

- 기존 manifest에 안정적인 앱 ID를 추가한다.
- 루트 서비스 워커는 push/notificationclick 처리만 담당한다. 로그인 페이지와 회원 데이터의 오프라인 캐시는 추가하지 않는다.
- 기존 `/welcome`에 Safari → 공유 → 홈 화면에 추가 → 아이콘에서 열기 → 로그인 → 알림 켜기 안내를 추가한다.
- 계정 모달의 알림 영역은 브라우저 지원, 홈 화면 설치 필요, 권한 차단, 서버 등록, 실패 및 재시도를 구분한다.
- 권한 요청은 사용자가 버튼을 누르는 시점에 시작한다. 자동 권한 팝업은 띄우지 않는다.

## 알림 서버

- 별도 private 웹 구독·전송 저장소와 웹 이벤트 확장 상태를 둔다.
- 기존 이벤트 및 회원별 알림 설정/수신 자격 판정을 재사용한다.
- 등록/해제는 인증 사용자와 기기 소유권을 검증하며 push endpoint를 클라이언트에 반환하거나 로그에 남기지 않는다.
- 전송 endpoint는 HTTPS 및 공식 푸시 제공자 호스트만 허용한다. 요청 본문/타임아웃/재시도/만료 처리에 상한을 둔다.
- VAPID 키 쌍은 인증된 Edge Function에서 한 번 생성하고 비밀키를 Supabase Vault에 저장한다. 공개키 RPC만 브라우저에 노출하며 서버 전용 RPC에서 실제 저장된 키를 읽는다. 동시 초기화 시 기존 키를 유지하고 Vault 유실 시 자동 재발급하지 않는다.
- 로그아웃 시 구독을 해제하고 안전한 기기 상태를 남겨 등록 해제 실패도 다음 실행에서 정리한다.
- 사용자에게 보이는 알림은 기존 업무 문구·분류·경로를 유지하고 외부 URL/다른 계정으로의 이동을 막는다.

## 배포 순서

검증 → 추가 스키마 적용/확인 → 비밀키 설정 및 웹 푸시 함수 배포/스케줄 → 일반 PR 및 검사 → main 병합/자동 운영 배포 → 운영 URL/로그 확인 → iPhone 실기기 확인.
