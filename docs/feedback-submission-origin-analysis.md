# 제보 접수 경로 기록 분석

## 목적과 결정

회원은 기존 양식으로 의견만 제출한다. 새로 제출된 제보의 원천 `feedback` 행에 웹 또는 앱 접수 경로를 자동 기록하여 이후 작업자가 원본 데이터를 볼 때 참고할 수 있게 한다. 선택 항목이나 분류 작업은 추가하지 않는다.

## 현재 경로

- 웹은 `components/feedback-hub.tsx`에서 `feedback`에 직접 INSERT한다.
- 앱은 `src/domain/feedback-submission.ts`의 payload를 `feedback`에 INSERT한다.
- 이전 앱 설치본과 기존 제보의 실제 접수 경로는 신뢰할 만한 데이터가 없다.
- 회원 공개 목록은 별도 `feedback_feed` 테이블이다. 출처는 여기에 복사할 필요가 없다.
- GitHub 발행은 시스템 제보와 명시적 공개 동의로만 허용된다. 접수 경로는 그 판단과 관계없다.

## 완료 기준

기존 행과 컬럼을 보내지 않는 이전 앱의 새 행은 `NULL`로 남는다. 새 웹은 `web`, 새 앱은 `app`을 보낸다. 그 밖의 값은 DB가 거절한다. 처리 상태와 운영진 답변을 바꿔도 경로는 유지된다. 기존 공개 범위와 GitHub 발행 동작은 유지된다.
