# 회원 상세 오버롤 표시 설계

- orchestrator: Codex
- 화면 방향: 기존 동호회 운영 화면의 명료한 UI와 디자인을 보존한다. impeccable의 기존 화면 확장 지침과 design-taste-frontend의 맥락 우선 기준을 적용한다.
- 회원 상세의 기본 정보 다음에 MemberOverallPanel을 바로 배치한다. 기존 육각형 그래프·수치 목록·수정·미평가·오류·재시도 UI를 재사용한다.
- 별도 능력치 펼침 상태와 진입 버튼을 제거한다. 능력치 조회는 해당 회원 상세를 열었을 때 시작하며 목록만 볼 때는 실행하지 않는다.
- 기존 access.isCurrent 조건과 scope·memberId·menuGeneration 키를 유지한다. 계정·권한·대상 변경 및 패널 종료 시 이전 응답을 폐기하는 기존 컴포넌트를 사용한다.
- ratings.manage의 서버 RPC 검증을 재사용한다. profiles나 공개 응답에 점수를 추가하지 않는다.
- API·스키마·패키지·스타일 변경 없음. 자동 팀 편성 방식과 기존 전화·연락처·관리 메뉴 유지.
- 모바일 브라우저에서도 현재 레이아웃과 스크롤·Escape·포커스 복원을 확인한다. 모바일 앱 코드는 변경하지 않는다.
- 검증은 합성 인증·REST를 사용하는 기존 브라우저 픽스처로 수행하며 운영 회원의 데이터를 읽거나 수정하지 않는다.
