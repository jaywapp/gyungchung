# 방문자 홈 히어로 모션 시안 (2026-09-30)

로그인하지 않은 방문자가 보는 홈 히어로에서 큰 제목 `우리의 주말, / 우리의 풋살.` 자리를 모션 그래픽으로 바꾸는 시안 3종입니다.
사용자가 하나를 고른 뒤에 운영 코드(`components/clubhouse.tsx`의 `Home`, `app/globals.css`의 `.hero` 이하)를 구현합니다.

## 공통 사항

- 교체 범위는 `.hero-copy` 안의 `h1` 한 자리입니다. eyebrow, lead-row, CTA, 오른쪽 다음 일정 패널, 사이드바·하단 탭 바는 운영 화면 구조를 그대로 옮겼습니다.
- 슬로건은 `<h1 class="sr-only">우리의 주말, 우리의 풋살.</h1>`로 남겨 스크린 리더와 SEO가 읽습니다. 모션 영역은 `aria-hidden="true"`입니다.
- 색은 `app/globals.css`의 `:root` / `:root[data-theme="dark"]` 토큰만 씁니다. 새로 만든 값은 코트 선용 `--chalk`(`--ink` 16%)와 `--chalk-strong`(30%)뿐이며, 둘 다 글자가 아닌 장식선이라 대비 기준 대상이 아닙니다. 글자는 모두 기존 `--ink`, `--brand`, `--on-navy`, `--on-highlight` 조합이라 두 모드에서 4.5:1 이상입니다.
- 폰트는 Google Fonts의 Archivo(영문·숫자)와 Noto Sans KR입니다. 스택은 `"Pretendard Variable", Pretendard, "Noto Sans KR", ...`로, Pretendard가 없는 시안 환경에서 Noto Sans KR로 폴백합니다.
- 반경은 카드 16px, 버튼 12px, 칩 999px, 전광판 타일 10px(`--radius-inner`)를 씁니다.
- 모든 애니메이션은 Web Animations API로 한곳(`Motion`)에서 관리합니다. 무거운 라이브러리, 동영상, 외부 이미지는 쓰지 않았습니다.
  - 화면 밖(IntersectionObserver)이거나 탭이 숨겨지면(`visibilitychange`) 멈추고, 돌아오면 이어서 재생합니다.
  - `prefers-reduced-motion: reduce`이면 모든 애니메이션을 즉시 끝 상태로 보내 완성된 정지 화면을 보여 줍니다.
  - 창 폭이 바뀌면 끝 상태로 다시 그립니다(재생 중 위치가 어긋나지 않도록).
- 샘플 일정(10월 4일 일요일 08:00, 세븐풋살장, 정원 18명, 제목 `일요 정기 풋살`)은 시안용 데이터입니다. 제목은 임의로 붙였습니다.
- 오른쪽 패널의 `WEEKLY SAT / SUN`은 운영 코드 문구를 그대로 옮긴 것입니다. 클럽 정보(매주 일요일)와 다르므로 구현할 때 함께 고칠지 확인이 필요합니다.
- 사이드바의 테마 스위치는 시안 상단 막대의 테마 전환과 겹쳐서 뺐습니다.

## 프리뷰 방법

각 파일은 단독 실행되는 HTML입니다. 브라우저에서 바로 엽니다.

- `concept-a.html`, `concept-b.html`, `concept-c.html`
- 상단 막대: 데스크톱/모바일(390px 기기 틀) 전환, 라이트/다크 전환, `정지 화면`(줄인 모션 설정에서 보이는 화면 미리보기), `다시 재생`
- 주소 끝에 `#dark` 또는 `#light`를 붙이면 그 테마로 엽니다. 없으면 OS 설정을 따릅니다.
- 폭 600px 이하 기기에서 열면 기기 틀 없이 앱이 전체 화면으로 보입니다.

## 콘셉트 A. 궤적 드로잉

한 줄 요약: 분필 같은 코트 라인이 그려지고, 페널티 마크에서 찬 공이 로브로 날아와 둘째 줄 아래를 굴러가며 글자를 하나씩 들어 올린 뒤 마침표 자리에 멈춥니다. 공이 곧 슬로건의 마침표입니다.

| 시간(초) | 동작 |
|---|---|
| 0.0 - 1.3 | 코트 외곽선, 하프라인, 센터서클, 양쪽 페널티 에어리어가 순서대로 그려짐 (선 5개, 0.09초 간격) |
| 0.25 - 0.95 | 첫 줄 `우리의 주말,`이 아래에서 올라오며 나타남 |
| 1.0 | 오른쪽 페널티 마크에서 킥 (작은 원이 퍼지는 피드백) |
| 1.0 - 2.0 | 공이 코트를 가로지르는 로브. 정점에서 1.55배로 커졌다가 작아짐(위에서 내려다본 높이감) |
| 2.0 - 2.95 | 공이 둘째 줄 밑을 굴러가며 `우 리 의 풋 살`이 공이 지날 때마다 하나씩 올라옴 |
| 2.95 - 3.25 | 공이 톡 튀어 마침표 자리에 안착 |
| 3.25 - 3.5 | 공이 마침표 크기로 줄어듦 |
| 3.5 - 4.2 | 궤적 선이 옅어져 흔적으로 남음 |

- 한 번 재생 후 멈춥니다(약 4.2초).
- 정지 화면: 코트 라인, 옅은 궤적, 둘째 줄 밑줄, 마침표가 된 공.
- 장점: 슬로건 크기와 위계를 그대로 유지해 기존 히어로와 가장 가깝습니다. 공이 마침표가 되는 순간이 기억에 남는 한 장면이 됩니다.
- 단점: 글자 위치를 재서 경로를 만들므로 폰트 로딩과 리사이즈 처리가 필요합니다. 궤적 선이 첫 줄 위를 지나갑니다(옅은 선이라 가독성 영향은 작음).
- 구현 난이도: 중. 인라인 SVG 2장과 글자 측정 로직(약 120줄)이 들어가며, 클라이언트 컴포넌트 하나로 분리하면 됩니다.

## 콘셉트 B. 전술판

한 줄 요약: 흰 전술판 위에서 우리 팀(채운 점 5개)과 상대(빈 점 5개)가 2-2, 1-2-1, 3-1로 포메이션을 바꾸고, 포메이션이 잡힐 때마다 슬로건 한 줄씩 분필로 쓰듯 열립니다. 마지막에 패스 길이 화살표로 그려집니다.

| 시간(초) | 동작 |
|---|---|
| 0.0 - 0.5 | 전술판이 살짝 올라오며 나타남 |
| 0.15 - 0.95 | 선수 점이 2-2 위치에 차례로 등장, 포메이션 칩 `2-2` |
| 0.7 - 1.3 | 첫 줄 `우리의 주말,`이 왼쪽부터 쓰이듯 드러남 |
| 1.4 - 2.2 | 1-2-1로 이동, 칩 `1-2-1` |
| 2.5 - 3.3 | 3-1로 이동, 칩 `3-1` |
| 3.0 - 3.6 | 둘째 줄 `우리의 풋살.`이 드러남 |
| 3.4 - 4.3 | 패스 길 화살표 2개가 그려짐 |
| 이후 | 아주 느린 루프: 7초마다 1초 동안 다음 포메이션으로 이동(21초 주기) |

- 5초 넘게 움직이므로 전술판 오른쪽 위에 일시정지/재생 버튼을 두었습니다(WCAG 2.2.2).
- 정지 화면: 3-1 포메이션, 패스 길 화살표, 슬로건 두 줄. 일시정지 버튼은 숨김.
- 장점: 경기를 준비하는 팀이라는 이야기가 가장 분명하고, 루프가 느려 오래 봐도 지루하지 않습니다. 측정 로직이 없어 가장 견고합니다.
- 단점: 슬로건 글자가 작아지고 전술판이 세로 공간을 더 씁니다(데스크톱 히어로 높이가 약 770px로 늘어남. 1440×900에서는 CTA가 첫 화면에 보이지만 768px 높이 노트북에서는 CTA가 경계에 걸릴 수 있음). 오른쪽 일정 카드와 카드가 둘이 되어 화면이 다소 무거워집니다.
- 구현 난이도: 중. SVG 한 장과 좌표 표, 루프 제어, 일시정지 버튼 상태가 필요합니다.

## 콘셉트 C. 킥오프 전광판

한 줄 요약: 경기장 전광판처럼 시계가 `07:57`에서 `08:00`(실제 일요일 킥오프 시각)으로 넘어가며 `SUN KICK OFF` 램프가 켜지고, 빈 타일들이 몇 글자를 스쳐 굴러가다 슬로건에 멈춥니다.

| 시간(초) | 동작 |
|---|---|
| 0.0 - 0.4 | 빈 타일 10개와 시계가 켜짐 |
| 0.45 / 0.8 / 1.15 | 시계가 07:58, 07:59, 08:00으로 넘어감 |
| 1.15 - 1.5 | `SUN KICK OFF` 램프가 라임색으로 켜짐 |
| 1.3 - 2.4 | 첫 줄 타일(네이비)이 왼쪽부터 0.09초 간격으로 굴러 `우리의 주말`에 멈춤, 쉼표 등장 |
| 1.75 - 2.9 | 둘째 줄 타일(라임)이 굴러 `우리의 풋살`에 멈춤, 마침표 등장 |

- 한 번 재생 후 멈춥니다(약 2.9초).
- 정지 화면: `SUN KICK OFF` 램프 켜짐, `08:00`, 슬로건 타일 두 줄.
- 장점: 가장 짧고 에너지가 큽니다. 전부 `transform`/`opacity`만 쓰고 측정이 없어 성능과 구현 부담이 가장 작습니다. 일요일 08:00이라는 실제 정보가 들어갑니다.
- 단점: 네이비·라임 타일 덩어리가 커서 오른쪽 네이비 패널과 겹쳐 화면이 무거워 보일 수 있습니다. 다크 모드에서 네이비 타일과 배경 차이가 작아 테두리(`--card-edge`)로 구분합니다. 한 글자씩 끊긴 타일이라 슬로건이 문장보다 표지판처럼 읽힙니다.
- 구현 난이도: 하. 타일 마크업과 CSS 키프레임만으로도 옮길 수 있습니다.

## 성능·접근성 메모

- 움직이는 속성: A는 공·글자의 `transform`/`opacity`와 SVG 선의 `stroke-dashoffset`(코트 선 5개와 궤적 1개), B는 점의 `transform`, 화살표의 `stroke-dashoffset`, 첫·둘째 줄의 `clip-path`, C는 `transform`/`opacity`만 씁니다. 레이아웃 속성(`width`, `top` 등)은 움직이지 않습니다.
- 시안은 Web Animations API를 쓰며, 운영 이식 때도 그대로 쓰거나 CSS 키프레임으로 옮길 수 있습니다. 새 의존성은 필요 없습니다.
- 스크린 리더는 숨긴 `h1`만 읽습니다. B의 일시정지 버튼만 키보드 포커스를 받으며 `aria-pressed`와 이름(`전술판 움직임 일시정지` / `재생`)이 바뀝니다.
- 모션을 줄인 설정에서는 시작하지 않고 완성 화면만 보여 줍니다.

## 추천안: A. 궤적 드로잉

- 교체 대상이 슬로건 제목이므로, 글자의 크기와 위계를 지키면서 모션을 얹는 A가 요구에 가장 가깝습니다. B는 슬로건이 작아지고, C는 슬로건이 타일로 쪼개집니다.
- 공이 마침표가 되는 한 장면이 브랜드 문구와 풋살을 한 번에 묶습니다. 모션이 끝나면 조용한 코트 라인과 밑줄만 남아 반복 방문에도 거슬리지 않습니다.
- 한 번(약 4초) 재생 후 멈춰 일시정지 버튼이 필요 없고, 히어로 높이가 기존과 같아 첫 화면 CTA 위치도 바뀌지 않습니다.
- 대안: 구현 부담을 최소로 하려면 C, 팀 이야기를 더 드러내고 싶다면 B를 권합니다.
