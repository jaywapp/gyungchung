App icon · round 2 · B & C

B와 C를 더 다듬은 여섯 가지

1차에서 고른 B(GC / FC 2단)와 C(킥오프 심볼)를 각각 세 갈래로 나눴습니다. 각 방향의 첫 번째는 1차 시안 그대로입니다. 고른 아이콘은 웹사이트(파비콘, 홈 화면 웹앱)와 Android·iOS 앱에 함께 씁니다.

B · GC / FC 2단

B1

기본 2단

1차 시안 그대로
  • 장점 스플래시 로고의 글자·라임 F·공 마침표를 그대로 담습니다.
  • 주의 29px 이하에서는 글자가 흐려집니다.
B2

하프라인 분할

두 줄 사이를 하프라인이, 둘레를 센터서클이 지나감
  • 장점 글자와 경기장이 한 그림이 되어 스플래시 첫 장면과 가장 비슷합니다.
  • 주의 선이 늘어나 작은 크기에서는 B1보다 조금 복잡해 보입니다.
B3

계단 배치

FC를 오른쪽으로 밀어 이탤릭 기울기를 따라 내려가는 두 줄
  • 장점 글자를 가장 크게 쓸 수 있어 B 중 작은 크기에서 가장 잘 읽힙니다. 앞으로 달려 나가는 느낌이 납니다.
  • 주의 가운데 정렬이 아니라 Android 원형으로 잘릴 때 양 끝이 안전 영역에 가깝습니다.

C · 킥오프 심볼

C1

기본 궤적

1차 시안 그대로
  • 장점 어떤 모양으로 잘려도 형태가 유지되고 스플래시 첫 장면과 이어집니다.
  • 주의 이름이 없어 아이콘만으로 경충FC라는 걸 알기 어렵습니다.
C2

굵은 센터서클

궤적 없이 굵은 선과 공 하나
  • 장점 가장 단순해서 16px 탭에서도 형태가 또렷합니다.
  • 주의 단순한 만큼 다른 축구 앱 아이콘과 비슷해 보일 수 있습니다.
C3

잔디 피치

남색 대신 피치 녹색 바탕과 잔디 줄무늬
  • 장점 한눈에 축구장으로 읽히고 홈 화면에서 색으로 구분됩니다.
  • 주의 스플래시(남색)로 넘어갈 때 바탕색이 바뀝니다. 녹색은 웹의 피치 토큰(#124a33)입니다.
