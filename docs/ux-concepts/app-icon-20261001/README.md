# 앱 아이콘 시안 (2026-10-01)

웹사이트(파비콘, 홈 화면 웹앱)와 Android·iOS 앱에 함께 쓸 아이콘 시안입니다.

- `concepts.html`: 1차 5종(A GC. 모노그램, B GC / FC 2단, C 킥오프 심볼, D 라임 배지, E 한글 경충)
- `variants.html`: 2차 6종(B1~B3, C1~C3). 사용자가 1차에서 B와 C를 골라 더 나눈 시안입니다.

## 결정 (사용자, 2026-10-01)

- 아이콘은 **B(GC / FC 2단, 1차 시안 그대로)**로 정했습니다. 남색 바탕에 흰 GC·C, 라임 F와 라임 공 마침표입니다.
- 같은 워드마크로 가로 로고를 만듭니다. 어두운 배경용과 밝은 배경용 두 가지입니다.
