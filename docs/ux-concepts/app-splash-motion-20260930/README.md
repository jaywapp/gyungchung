# 앱 스플래시 모션 시안 (2026-09-30)

웹앱(PWA)과 Expo 앱(`docs/mobile-app-design.md`)에서 앱을 열 때 보이는 시작 화면 모션 시안 3종입니다.
사용자가 A안을 골랐고(2026-09-30), 워드마크는 `경충FC` 대신 `GCFC`로 바꾸기로 했습니다. 이후 `docs/app-splash-motion-20260930-{analysis,design,tasks}.md`를 쓰고 구현합니다.

- 시안: `splash.html` (세 시안을 한 페이지에서 비교, 다시 재생·첫 프레임·느리게 보기 지원)

## 공통 사항

- 운영체제 스플래시는 정지 화면만 허용하므로, 각 시안의 첫 프레임을 정지 화면 이미지로 쓰고 같은 그림 위에서 모션을 이어 붙입니다.
- 스플래시 바탕은 두 테마 모두 `#0b1f33`(라이트 `--navy`)입니다. 공과 엠블럼은 `--highlight`, 엠블럼 글자는 `--on-highlight`입니다.
- 끝 화면은 로그인 홈(매치 콘솔)이고, 상단 로고(`.club-crest`)와 엠블럼 위치를 맞춰 넘깁니다.
- 탭하면 건너뛰고, 움직임 줄이기 설정에서는 재생하지 않습니다. 브라우저 탭으로 연 일반 방문에는 재생하지 않습니다.

## 시안

| 시안 | 길이 | 내용 | 어울리는 경우 |
|---|---|---|---|
| A 킥오프 궤적 | 1.7초 | 공이 날아와 '경충FC' 밑을 굴러가며 글자를 띄우고 마침표로 멈춤 | 웹 히어로 모션과 인상을 통일. 첫 실행용 |
| B 골망 흔들기 | 1.3초 | 슈팅이 골망에 꽂히고 엠블럼이 튀어나와 상단 로고로 이동 | 힘 있는 브랜드 인상, 매 실행 |
| C 코트 펼치기 | 0.8초 | 엠블럼 테두리가 코트 라인으로 펼쳐지고 남색 바탕이 로고로 모임 | 가장 짧고 조용함, 매 실행 |

## 플랫폼별 구현 방향

- PWA: 지금은 `manifest`가 없어 먼저 추가합니다(아이콘, `background_color`, iOS `apple-touch-startup-image`). 모션은 `display-mode: standalone`일 때만 SVG와 Web Animations API로 재생합니다.
- Expo: `expo-splash-screen`에 첫 프레임 이미지와 배경색을 지정하고, `preventAutoHideAsync`로 붙잡은 뒤 `react-native-reanimated`와 `react-native-svg`로 같은 모션을 재생합니다.
- 좌표와 타이밍은 공용 모듈 하나에 두어 두 플랫폼이 함께 씁니다.
