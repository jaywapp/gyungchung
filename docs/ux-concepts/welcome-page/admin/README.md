# 관리자 공통안: 웰컴 페이지 관리

기존 관리 콘솔(`components/admin-console.tsx`)의 "운영" 그룹에 "웰컴 페이지 관리" 탭을 더하는 안입니다.
공개 시안 어느 것을 골라도 같이 씁니다. 실행 방법은 [상위 README](../README.md)를 봅니다.

## 구성

- 콘솔의 사이드바, 페이지 머리말, 그룹 버튼, 밑줄 탭, 입력 필드, 토스트, 확인 창은 `app/globals.css`의 현행 규칙을 그대로 옮겼습니다. 새로 만든 것은 `welcome-*` 규칙뿐이고 같은 토큰과 반경, 44px 컨트롤 높이를 씁니다.
- 접근은 계획된 `welcome.manage` 권한 기준입니다. 권한이 없으면 편집 화면 대신 안내를 보여 줍니다.
- 상태 쌍: 왼쪽 "방문자가 보는 게시본"(상태, 게시 시각, 게시한 사람, 공개 페이지 열기), 오른쪽 "편집 중인 초안"(상태, 저장 시각, 저장한 사람). 초안을 고치는 동안에도 게시본 칸은 바뀌지 않습니다.
- 편집 영역 4개: 기본 안내, 회칙, 운영진 소개, 앱 다운로드. 저장하지 않은 변경이 있는 영역에는 점 표시와 읽기용 문구가 붙습니다.
- 아래 고정 막대: 현재 상태 한 줄과 "초안 저장", "미리보기", "게시". 게시는 저장된 초안에 미게시 변경이 있을 때만 켜집니다.
- 운영진 소개 영역 맨 위에 "공개 이름, 직책 표시명, 소개는 공개 페이지에만 쓰이며 계정의 회원 유형, 실제 직책, 시스템 권한은 바뀌지 않는다"는 안내를 둡니다.
- Android 버전, 빌드 코드, 파일 크기, 확인 시점은 읽기 전용 상자입니다. 운영진은 노출 여부와 설치 안내만 고칩니다.
- iOS는 상태(준비 중, 테스트 참여, 출시, 숨김), 배포 주소, 안내 문구를 고칩니다. 테스트 참여와 출시는 https 주소가 있어야 게시됩니다.
- 미리보기는 전체 화면으로 열리고 PC와 모바일을 바꿔 볼 수 있습니다. 화면 맨 위에 "초안 미리보기입니다. 아직 게시되지 않은 내용입니다." 띠가 붙습니다. 선택된 03 구단 소개형을 넣어 두었습니다.

## 상태

검토 도구의 "편집 상태"에서 바꿉니다. 화면에서 직접 입력하거나 버튼을 눌러도 이어집니다.

| 상태 | 화면 | 스크린샷 |
| --- | --- | --- |
| 게시본과 같음 | 저장과 게시 모두 꺼짐 | |
| 저장 안 한 변경 | 초안 칸 "저장 안 한 변경", 저장만 켜짐 | `pc-dark-unsaved.png` |
| 저장 중, 게시 중 | 해당 버튼이 진행 표시로 바뀌고 다시 누를 수 없음 | |
| 저장됨, 미게시 | 토스트 "초안을 저장했습니다. 공개 페이지는 아직 바뀌지 않았습니다." 게시 켜짐 | `pc-draft-saved.png`, `pc-full.png` |
| 저장 실패 | 작성 내용 유지, "다시 저장" | `pc-save-failed.png` |
| 게시 완료 | 게시본 시각 갱신, 토스트 | `pc-published.png` |
| 게시 실패 | 게시본과 초안 모두 그대로, "다시 게시" | `pc-publish-failed.png` |
| 동시 편집 충돌 | 저장을 멈추고 내 변경 유지, "최신 초안과 비교" 또는 "내 변경을 버리고 최신 초안 불러오기" | `pc-conflict.png`, `mobile-conflict.png` |
| 필수 항목 누락 | 빠진 항목 목록, 누르면 해당 영역의 입력란으로 이동 | `pc-invalid.png` |
| 저장 안 하고 이탈 | 확인 창. 기본 포커스는 "계속 편집" | `pc-leave-confirm.png` |
| 미리보기 | 초안 표시 띠, PC와 모바일 전환 | `pc-preview.png`, `pc-preview-mobile.png` |
| 최초 게시 전 | 게시본 칸 "아직 게시한 적이 없습니다", 방문자에게는 준비 중 안내 | |
| 권한 없음 | 편집 화면 대신 권한 안내 | |

## 시안의 한계

- 날짜, 시각, "운영진 이름 예시 1"은 배치를 보기 위한 자리표시자입니다.
- "최신 초안과 비교" 화면 자체는 그리지 않았습니다. 충돌 안내와 선택지까지만 있습니다.
- 회칙 편집은 장 2개만 보여 줍니다. 조항 추가, 순서 이동, 삭제 버튼은 모양만 있습니다.
- 모바일에서 현행 하단 탭 바는 생략했습니다. 구현할 때 작업 막대를 탭 바 위에 올립니다.
