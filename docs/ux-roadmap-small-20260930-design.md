# UX 로드맵 남은 항목(소규모) — 설계

## 로그아웃
- `AccountModal`, `UnlinkedAccountModal`의 로그아웃을 `cta ghost`(2px 잉크 테두리, 투명)로 바꾼다.

## 빈 상태
- 홈 회비 카드
  - 비로그인: 본문 크기 회색 문장 '로그인하면 내 회비 납부 상태를 확인할 수 있습니다.'와 '로그인' 링크를 보여 준다. '상세 보기'는 로그인 회원에게만 둔다.
  - 내역 없음: '아직 등록된 회비 내역이 없습니다.'
  - 새 클래스 `.panel-empty`(15px, `--muted`)를 쓰고, `.panel`의 `min-height: 270px`을 없애 높이를 내용에 맞춘다.
- 페어플레이어: 다른 랭킹 표와 같은 제목·설명 구조에, `table-wrap` 안의 `Empty`('연말 선정 예정')를 넣는다.

## 랭킹
- 첫 행 기준 CSS를 버리고 `rank === 1`이면 `.top`(highlight)을 붙인다.
- 같은 순위가 둘 이상이면 `.tied` 알약형 배지에 `T{rank}`를 쓰고, `aria-label`은 '공동 N위'로 둔다. 순위 계산(`buildSeasonRankings`)은 이미 공동 순위를 같은 등수로 매기므로 바꾸지 않는다.
- 이름 `th[scope=row]`는 16px, 800, `--ink`로 둔다.
- 1051px 이상에서 `.ranking-layout`을 3열로 두고, 페어플레이어는 전체 폭을 쓴다.

## 타이포 스케일
- 스크립트로 `font-size`를 12/14/16/20/28/48 단계로 맞춘다.
  - 대응: 9–11→12, 13→14, 15·17→16, 18–23→20, 24–30→28, 34–40→32(모바일 제목 단계), 42·44→48
- 페이지 제목은 `clamp(32px, 5vw, 56px)`이고, 상세·OAuth 제목도 56px을 넘지 않는다.
- 제목 자간 -0.03~-0.05em을 -0.02em으로 맞춘다.
- 제외: 로고(`.crest`), 장식 숫자(`.giant-number`, `.member-number`, `.notice-index`), 데이터 숫자(날짜·점수·금액), 개편을 앞둔 `.hero`
- 12px은 배지·라벨 단계로 남긴다.

## 의견 목록
- `FeedbackCard` 제목을 `aria-expanded` 토글 버튼으로 바꾼다.
  - 펼치면 본문, GitHub Issue, AI 답변이 보인다. 접힌 상태에서도 답변이 있으면 '답변 있음' 배지를 보여 준다.
  - GitHub 공개 실패의 재시도 버튼은 접혀도 보인다.
- 목록은 10건씩 보여 주고 '더 보기 · 남은 N건'으로 늘린다. 탭을 바꾸면 10건으로 돌아간다.
- 761px 이상에서 `.voice-form`은 `position: sticky; top: 124px`로 둔다. 화면보다 길면 폼 안에서 스크롤한다.

## 기타
- `.page`의 세로선 그라디언트를 제거한다.
- 관리 화면
  - 2단 탭을 밑줄형(3px `--brand`)으로 바꾼다.
  - `AdminRow`에 `badges`를 추가해 회원(직책·시스템 관리자·상태), 회비·용병 회비(납부 상태), 의견(처리 상태), 참여(진행 상태)를 기존 `.status` 배지로 보여 준다.
- 회비 헤더: 한 줄에 `h2 회원별 납부 현황` · 필터 · 등록 버튼을 두고, 요약 4칸은 그 아래 전체 폭 4열로 둔다.
- 업데이트 노트 1건(source `request`)을 추가한다.
