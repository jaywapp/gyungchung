# 오버롤 기본 그래프와 0점 기준 설계

orchestrator: Codex

- 기존 Operate UI와 육각형 SVG·수치 목록·색상·레이아웃을 재사용한다. 기존 화면 상태 변경이므로 새 콘셉트·디자인 시스템 변경 없이 impeccable·design-taste-frontend의 기존 화면 보존 지침을 적용한다.
- 데이터가 성공적으로 비어 있으면 row=null을 유지하면서 표시·편집 초기값만 0으로 만든다. 오버롤 0과 미저장 안내를 함께 표시한다.
- load 성공은 항상 editing=false. 수정은 ready 상태에서 허용하고, 미평가도 0 초기값으로 진입한다. 취소는 미평가/기평가 모두 표시 화면으로 되돌리며 서버 조회·저장 없이 기존 표시를 유지한다.
- 수치 입력은 0~100 정수. 빈 문자열은 0으로 해석한다. 소수·음수·100 초과·잘못된 문자열과 불완전하거나 추가 필드가 있는 서버 점수 객체는 거부한다.
- DB 변경은 각 점수 CHECK 하한과 private 저장 helper의 점수 검증만 1에서 0으로 확장한다. 기존 행·revision·작성자·시간·권한·잠금·RLS·CAS와 공개 wrapper를 보존한다.
- 저장되지 않은 기본 0은 팀 평균에서 계속 제외한다. 저장된 0점 평가는 포함한다. 실제 평가 행의 존재와 숫자의 진위 여부를 혼동하지 않는다.
- 패널에서 기존 계정·권한·대상·마운트 세대 보호와 늦은 응답 폐기, Escape·포커스 복원을 유지한다.
- DB는 합성 PostgreSQL로 경계값·거부·CAS·권한 회귀를 먼저 검증하고 리뷰 후 운영에 additive 마이그레이션을 적용한다. 기존 회원 점수는 수정하지 않는다.
