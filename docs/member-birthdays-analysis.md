# 구성원 생일 계획
작성일: 2026-10-05

## 분석
사용자 요청: 구성원 생일을 캘린더에 표시하고 생일 데이터가 없는 본인에게 입력을 유도한다.
기존 프로필에는 생일이 없으며 가입 신청서의 birth_date는 별도의 민감한 원본이다. 신청서를 자동으로 재사용하지 않는다.
기존 회원 목록과 회비/프로필 이미지 접근 계약을 유지한다. 웹과 Android에서 같은 서버 계약을 사용한다.
적용 모델은 사용 가능한 GPT 모델로 역할을 배정한다.


확인 결과: 운영 가입 신청서 2건에 birth_date 값이 존재한다. 값 자체는 읽지 않았으며 이번 기능으로 복사하지 않는다.
