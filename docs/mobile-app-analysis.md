## 목표와 합의된 방향

경충FC 회원과 운영팀이 iOS·Android에 설치하여 쓰는 앱을 Expo/React Native 소스 하나로 제공한다. 기존 Next.js 웹과 Supabase 백엔드를 사용하며, 최신 웹의 매치 콘솔 디자인과 회원 업무 흐름을 모바일 화면으로 옮긴다.

| 항목 | 합의된 방향 |
| --- | --- |
| 계정 | 운영자 발급 전화번호·비밀번호 계정. 공개 회원가입, 문자 OTP, 소셜 로그인은 제공하지 않음 |
| Android | 서명된 APK를 팀원에게 직접 제공 |
| iOS | TestFlight 시험 후 App Review 및 Unlisted App 승인으로 링크 배포 |
| 접근 제어 | 회원 로그인·역할별 권한·RLS 적용. 미등록 앱 링크와 APK는 전달될 수 있음 |
| 저장소 | 기존 웹을 루트에 두고 `mobile/` 추가. 순수 로직만 필요할 때 공용 패키지로 추출 |

`mobile/`, Expo 설정, EAS 설정, 공용 패키지는 아직 없다. 모바일 개발·스토어 제출 작업은 미착수 상태다. 웹 UX 작업 완료를 모바일 작업 완료로 기록하지 않는다.

## 이전 기획에서 바뀐 점

1. 모바일 화면 기준을 최신 매치 콘솔 A안으로 구체화했다. 탭 구성과 홈 모듈, 회원 카드, 테마가 재설계 출발점이다.
2. 기존 후속 후보였던 시즌 랭킹과 기본 참여 기능을 1차 출시 추천 범위로 올렸다. 현재 홈과 하단 탭을 끝까지 사용할 수 있도록 하기 위한 제안이며, 범위 승인은 아직 필요하다.
3. 회원 공개 의견 게시판이 구현되어 Apple 사용자 생성 콘텐츠 요구사항을 구체적인 출시 조건으로 추가했다.
4. 기존 웹의 데이터 일괄 로딩은 ADR의 현행 유지 결정을 존중한다. 모바일에는 별도 데이터 서비스와 측정을 계획한다.
5. 미등록 앱 요청 시점을 정정했다. 정식 버전을 App Review에 제출한 뒤 요청할 수 있으며, 심사 통과만으로 미등록 배포가 자동 승인되는 것은 아니다.

## 1차 출시 추천 범위

| 구분 | 모바일 범위 | 상태 |
| --- | --- | --- |
| 첫 기술 검증 | 로그인·초기 비밀번호 변경·세션 복원, 하단 탭, 매치 콘솔, 일정 상세와 참석 응답, 라이트/다크/시스템 테마 | 계획 |
| 1차 출시 추천 | 기본 회원 프로필, 포지션별 회원 목록, 공지, 본인 회비 조회, 시즌 랭킹, 기본 투표·설문, 더보기와 업데이트·개인정보·지원 안내 | D01 승인 필요 |
| 조건부 확장 | 회원 공개 의견과 제보 작성, 선거·비밀투표, MOM 투표, 운영자 편집·출석·우승 회원 기록 | 기능별 권한·심사·회귀 검증 후 결정 |
| 후속 | 방문자 모션의 네이티브 구현, 푸시 알림 | 우선순위 미정 |

회비는 현재 납부 상태 조회와 총무 안내를 전환 대상으로 삼는다. 앱 내 결제 도입은 이 기획의 범위에 포함하지 않는다. 출시에서 제외된 기능의 버튼이나 홈 모듈은 제출 빌드에 미완성 상태로 남기지 않는다.

## 주요 제약과 위험

- `is_test_account`는 목록·랭킹 숨김 표식이다. 일반 공개 일정과 회원 조회를 포함한 모든 데이터의 시연 계정 격리를 보장하지 않는다.
- 승인 대기·비활동·프로필 미연결·초기 비밀번호 변경 상태를 모바일에서도 구분해야 한다. 로그인 성공을 활동 회원 권한으로 간주하지 않는다.
- 웹 화면은 DOM·CSS·Next Link·Web Animations API와 브라우저 저장소를 사용한다. 네이티브 UI와 저장소 어댑터 구현이 필요하다.
- 누적 일정·경기 중첩 조회와 저장 후 재조회는 모바일 네트워크에서 비용이 커질 수 있다. [기존 로딩 ADR](adr/0001-clubhouse-client-data-loading.md)을 기준으로 측정한다.
- [Apple 심사 지침](https://developer.apple.com/app-store/review/guidelines/)에 맞는 실제 기능과 접근 가능한 심사 환경이 필요하며, 현재 웹 디자인 완료만으로 승인을 보장하지 않는다.
