## 사용자 결정 (2026-09-30)

- 비로그인 방문자: 기존 슬로건 히어로 홈을 유지한다. 사용자가 슬로건 대신 모션 그래픽을 제안했다. 이 작업이 끝난 뒤 방문자 히어로용 모션 시안을 따로 만들어 고르게 한다.
- 운영진의 회원 수정·강퇴는 작은 카드의 '⋯' 메뉴에 모두 넣는다. 강퇴는 위험 색과 확인 대화상자를 유지한다.

## 시안이 다루지 않은 상태와 결정

| 상태 | 처리 |
|---|---|
| 다음 일정 없음 | 콘솔 자리에 '새 일정을 준비 중입니다' 빈 상태와 전체 일정 링크 |
| 일정 불러오기 실패 | 콘솔 자리에 기존 `LoadError` |
| 회원 프로필 미연결·승인 대기·비활동 | 콘솔은 그대로, 참석 영역은 `getRsvpViewModel`의 안내 문구(기존 규칙) |
| 정원 미설정 일정 | 칸 막대 없이 '참석 N명'만 |
| 포지션 미지정 회원 | '무관' 묶음과 같은 점선 아바타, 칩 문구 '미정' |

## 제약

- 인증·권한·비즈니스 로직과 DB는 바꾸지 않는다. 참석 저장은 기존 `setMyAttendance`를 쓴다.
- 기존 테스트 계약: `clubhouse.tsx` 안의 `<RsvpControls` 2회, `Home`·`UnlinkedAccountModal` 렌더링 테스트, 토스트 역할 속성
- 시안의 공지 작성자, '14명 응답' 같은 수치는 데이터에 없으므로 쓰지 않는다.
