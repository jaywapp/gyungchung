# 일정별 Player of the Match 분석
작성일: 2026-10-05
상태: 로컬 구현·검증 코드 준비, 일괄 검증 대기

사용자 요청: 일정별 최우수 선수를 투표로 뽑고, 일정 종료 후 기본 3일 동안 투표를 받으며 기간을 설정할 수 있게 한다.
사용자 작업 방식: 기능을 모아 두고 빌드·테스트·배포를 한 번에 진행한다. 지금 검사·빌드·DB 적용·commit·push·PR·배포·APK 발행을 실행하지 않는다.

기존 event_mom_votes는 일정 시작 후 무기한 변경 가능한 1인 1표다. 출석/지각 회원만 투표하고 본인에게 투표할 수 없다. 결과는 상위 3순위와 공동 순위를 반환하며 개인 표는 본인에게만 보인다. 기존 events에는 starts_at만 있다. 주간 일정 메모의 08:00~10:00은 기본 2시간 선택의 근거이며 실제 종료 사실로 저장하지 않는다.

새 화면은 기존 MOM을 Player of the Match로 확장한다. 별도 투표 테이블이나 새 시즌 점수 제도를 만들지 않는다. 기존 표와 기존 결과 반환형을 보존한다. 생일·전화 변경도 보존한다.

기본 경기 시간은 사용자에게 선택을 요청했다. 응답 전에는 기존 주간 일정에 맞춰 2시간을 사용한다. 운영진은 일정별 종료 시각을 변경할 수 있다.
