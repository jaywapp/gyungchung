# 일정 정원 및 RSVP 정책

## 기준

- 정원에는 RSVP가 `going`인 회원과 운영진이 일정에 배정한 용병을 모두 포함한다.
- 정원이 `null`이면 제한 없음으로 표시하며, 임박·초과 상태를 만들지 않는다.
- 잔여 좌석이 2자리 이하이면 `임박`으로 알린다. 잔여 0자리는 `정원 도달`, 음수는 `정원 초과`로 구분한다.

## RSVP 처리

정원 초과 상태에서도 참석 RSVP는 허용한다. 이미 정원이 찬 일정에 새로 참석을 누르면, 정원을 초과해 등록된다는 확인 문구를 먼저 표시한다. 이는 현장 조정 권한을 운영진에게 남기는 보수적 정책이며, 대기 명단이나 RSVP 상태 모델 변경은 이 범위에 포함하지 않는다.

## 화면 표기

홈 RSVP 패널, 일정 카드, 일정 상세는 모두 `참석 N / 정원 C명`과 잔여 좌석을 같은 계산으로 표시한다. 모든 유한 정원 표기에는 `용병 포함`을 함께 표시해 집계 기준을 명확히 한다.
