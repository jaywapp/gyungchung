# 회원 상세 오버롤 표시 분석

- 요청: 운영진 또는 시스템 관리자가 회원 한 명의 상세 화면을 열면 육각형 그래프를 확인한다.
- 현재 상태: PR #192에서 능력치 기능과 서버 권한 검증을 제공한다. 회원 상세에서는 추가 버튼을 눌러야 패널이 열린다.
- 결정: 상세 화면을 열 때 기존 패널을 즉시 표시한다. 점수가 있으면 저장된 그래프와 오버롤, 없으면 기존 입력 안내와 폼을 제공한다.
- 권한: 기존 ratings.manage를 유지한다. 일반 회원과 시스템 관리자가 권한을 제외한 운영진은 볼 수 없다.
- 범위: 웹 회원 상세의 패널 연결과 업데이트 안내. 기존 화면 확장이므로 디자인·권한·DB 구조 변경 없음.
- 앱: 사용자 웹 우선 정책에 따라 동기화 요청 대기.
- 확인 질문: 추가로 확정할 정보 없음. 사용자 요청 및 앞선 권한·점수 기준 유지.
- 완료 기준: 권한 보유자의 상세 진입만으로 그래프 표시, 권한 없는 계정의 패널·조회 없음, 미평가·조회 실패·재시도·키보드·늦은 응답 확인, 검사·빌드·PR 병합·운영 배포 완료.
