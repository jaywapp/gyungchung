## 반려 또는 정정

### 다크 모드

이번 작업에서는 반려한다. 현재 사이트는 크림색 종이 질감, 네이비, 그린을 중심으로 설계된 단일 브랜드 테마이며 다크 모드는 기능 결함이 아닌 선택 기능이다. 별도 디자인 기준과 대비 검증 없이 자동 색상 반전만 추가하면 브랜드 일관성과 가독성을 악화시킬 수 있다.

### R-1의 “날짜가 사라졌다”는 원인 설명

문장 그대로는 반려한다. 기존 DOM의 굵은 `08`은 월이 아니라 `getDate()`로 출력한 일(day)이었다. 다만 `2026 / 08 / 8월 토` 순서가 모호했다는 UX 지적은 타당하므로 표기 구조를 명확하게 수정했다.

### P3-7 단복수 미수정 판정

반려한다. 기존 코드에 이미 `memberCount === 1 ? "MEMBER" : "MEMBERS"` 처리가 있었다. 현재 회원 수가 2명이어서 화면에서 복수형만 관찰됐을 뿐이다.

### P3-10 전체 미수정 판정

부분 정정한다. 회비 표에는 2차 조치에서 이미 caption과 `scope`가 적용돼 있었다. 이번 조치에서 랭킹과 관리자 권한표까지 확대했다.

### SWR/TanStack Query 및 전면적인 라우트별 데이터 계층 전환

이번 결함 수정 범위에서는 반려한다. 중복의 직접 원인은 동일 인증 상태 이벤트에 대한 재호출이었고, 작은 가드와 프로필 쿼리 통합으로 해결됐다. 캐시 라이브러리 도입과 데이터 계층 전면 변경은 별도 성능 개선 과제로 분리하는 것이 안전하다.

## 검증 결과

- `npm run lint`: 통과
- `npm run build`: 통과
- Chrome 일반회원 새로고침 후 Supabase API 로그: **16개 엔드포인트가 각각 1회**, 총 16회
- `/profiles`: 1회
- `/rpc/get_member_directory`: 1회
- 익명 `get_member_directory` 실행 권한: 없음
- 로그인 회원 `get_member_directory` 실행 권한: 있음
- 익명 `profiles` 조회 권한: 없음
- Supabase 보안 점검: `get_member_directory`의 `SECURITY DEFINER` 경고는 의도된 설계다. 함수는 고정 `search_path`, 무인자 호출, `auth.uid()` 검사, 제한된 활성 회원 필드만 반환하며 실행 권한도 `authenticated`에만 부여했다.
- `/events`: 날짜 `2026 · 8월 / 08 / 토요일`, 지난 일정 버튼 44px·비활성 확인
- `/fees`: `h1 → h2`, 회비 표 caption 확인
- `/participation`: `h1 → h2` 확인
- 주 메뉴: 8개 모두 실제 `<a href>` 확인
- 라우트별 title 확인: `회원 | 경충FC`, `일정 | 경충FC`, `회비 | 경충FC`, `투표·설문 | 경충FC`
