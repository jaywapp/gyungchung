# 푸시 피드백 서버 분석

## 목표와 범위

기존 알림의 수신 자격, 계정 연결, 전송 lease, 운영 시작 시각을 유지하면서 PNC-01/02와 PNF-03~06의 서버 문구와 변경 시점 정보를 개선한다. 앱에는 기존 v1 이동·계정 검증 데이터와 함께 선택적 `data.display`를 전달한다.

## 현행 문제

- 참석 이벤트에는 변경 직후 참석 회원 수가 없다. 변경한 회원 자신도 정책에 따라 다시 받는다.
- 주소만 바뀌어도 장소 이름만 비교해 같은 이름을 반복한다.
- 의견 처리 상태만 바뀌었어도 기존 답변이 있으면 새 답변으로 표현한다.
- 자동 참석 안내와 운영진 재알림은 이미 `manual`로 구분되지만 문구가 같다.
- 전경 배너가 시스템 알림의 실제 제목·본문을 받지 못한다.

## 완료 기준

변경 직후 `attendance.status='going'` 회원 수를 스냅샷으로 저장하며 게스트는 제외한다. 참석 알림은 대상 회원에게 발송하지 않는다. 장소명과 주소는 각각의 실제 변경을 보여 준다. 의견 답변 등록·수정·삭제와 처리 상태 변경을 구분한다. 자동 안내와 운영진 재알림을 구분한다. 새 payload는 기존 v1 필드를 보존하며 이전 snapshot도 worker에서 처리한다.
