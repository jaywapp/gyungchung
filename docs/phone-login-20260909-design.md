# 전화번호 로그인 설계

orchestrator: Codex

- 공통 전화번호 정규화·입력 검사·초기 비밀번호 변환 함수를 사용한다.
- 홈과 관리자 도구 로그인에서 email/OAuth 분기와 계정 연결 동작을 제거한다. 과거 소셜 callback은 세션 교환 없이 전화번호 로그인 안내로 전환한다.
- Supabase의 기본 영속 쿠키와 자동 갱신을 유지한다. 인증 이벤트에서는 상태만 반영하고 데이터 로드는 별도 effect에서 실행한다. 일시적인 인증 연결 실패와 실제 로그아웃을 구분한다.
- 인증 초기화와 로그아웃 오류를 명시적으로 안내하고 실패를 성공으로 표시하지 않는다.
- 초기 비밀번호 교체는 기존 보안 동작대로 새 비밀번호 재로그인을 요구한다.
- 실제 세션 유지 검증은 새로고침·새 탭·토큰 갱신·로그아웃을 포함한다. 운영 계정 접근이 불가능하면 동일 SDK를 사용하는 격리된 테스트로 검증하고 한계를 기록한다.
- 테스트·lint·빌드·독립 리뷰 후 PR 병합 및 운영 배포 상태를 확인한다.
