# 회원 오버롤 분석

작성일: 2026-10-07 · 웹 우선

운영진이 회원별 6개 능력치를 입력하고 육각형 그래프와 오버롤을 확인한다. 팀 편성의 선수·팀별 밸런스 참고 자료로 제공한다. 일반 회원에게는 UI뿐 아니라 DB/API에서 능력치 접근을 차단한다. 시스템 관리자는 기존 권한 설정에서 해당 서비스를 직책별로 제외할 수 있다. 앱은 웹 점검 후 명시 동기화 요청까지 진행하지 않는다.

능력치 제안은 속도·슈팅·패스·드리블·수비·피지컬, 각 1~100 정수, 평균 오버롤이다. 사용자에게 항목/점수 기준을 질문했으며 응답 시 반영한다. 누락 회원과 게스트는 미평가로 구분하고 임의 기본 점수로 평균을 왜곡하지 않는다. 기존 공개 경기 평점(event_team_members.rating)과 별도 데이터로 관리한다.

완료 기준: 운영진 입력/수정·저장 오류/충돌 복구·육각형과 수치 대안·회원/팀 편성 참고·일반회원/비활동/초기비밀번호/권한제외 API 차단·계정/권한 변경 데이터폐기·웹 전체검사/DB격리회귀/운영배포확인.
