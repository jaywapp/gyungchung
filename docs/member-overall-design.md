# 회원 오버롤 설계

기존 Match Console의 회원 메뉴와 팀 편성 화면에 확장한다. 기존 색·탐색·글꼴을 유지하며 외부 차트 라이브러리 없이 SVG 육각형과 수치 목록을 제공한다. 6축 점수와 동일 가중 평균을 표현하고 미평가/로딩/조회실패를 구분한다.

권한키 ratings.manage를 별도 운영 서비스로 정의한다. 기본적으로 회장·부회장·총무와 시스템 관리자에게 제공하며 시스템 관리자가 기존 직책별 서비스 설정에서 제외할 수 있다. DB 권한 판정은 최신 회원/직책/서비스 자격을 검증한다. 능력치 데이터는 일반 회원 조회 경로 및 팀 명단 공개 구조에 합치지 않는다.

저장은 이름/직책 편집과 분리하고 대상 회원+6점수+기대revision을 검증하는 RPC로 처리한다. optimistic conflict 때 덮어쓰지 않고 재조회 경로를 제공한다. 인증/권한/대상 세대 변경 시 늦은 결과와 준비 입력을 폐기한다.

회원 메뉴에 운영진 전용 능력치 진입을 둔다. 팀 편성에는 선수 오버롤과 평가된 선수 기준 팀별 평균·평가인원/전체인원·미평가 안내를 보여준다. 능력치 요약을 공개 팀명/메모/평점에 저장하지 않는다. 기존 편성 알고리즘의 포지션·인원 동작은 이번 범위에서 유지한다.
