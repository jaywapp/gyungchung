# UX/UI 점검 보완 분석

orchestrator: Codex

## 요구와 근거
- 사용자는 UX/UI 점검 결과의 모든 문제를 확인하고 수정하도록 요청했다.
- 대상: 계정 미연결 문의 동선, 홈 일정·회비 상태 혼선, 모바일 제목 과대 표시, 일정 관리 키보드 접근성.
- 운영 브라우저에서 일정 조회 실패와 하단의 일정 없음 표시가 동시에 관찰됐다. 네트워크 실패의 운영 원인은 확정하지 않았다.
- 기존 녹색·네이비, 콘텐츠와 화면 구조를 유지하는 국소 결함 수정이다. 신규 화면 또는 주요 디자인 변경이 아니므로 콘셉트 3종 선택 절차는 적용하지 않는다.
- impeccable 및 design-taste-frontend를 적용한다. 회원 업무 화면은 Operate 모드로 평가하고 마케팅 스타일 규칙은 홈의 해당 부분에만 적용한다.

## 가정과 범위
- 검증된 운영진 연락처가 저장소에 없으므로 연락처를 만들거나 개인정보를 노출하지 않는다. 작동하지 않는 내부 문의 링크를 없애고 기존 계정 등록 안내와 전달할 내용을 제공한다.
- Supabase 인증·DB 정책은 유지한다. 미연결 사용자의 의견 제출 권한을 확대하지 않는다.
- 현 브랜치와 origin/main의 파일 차이가 없음을 확인하고 최신 main에서 수정 브랜치를 생성했다.
- 프로젝트 AGENTS.md의 검사·빌드·커밋·PR·병합·배포 확인 플로우를 따른다.
