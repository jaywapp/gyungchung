# 오버롤 기본 그래프와 0점 기준 분석

- 사용자 확정 요청: 기본은 그래프를 표시하고 수정 버튼을 눌렀을 때 수치를 입력한다. 수치가 없으면 0이다.
- 현재: 저장된 회원만 기본 그래프를 표시한다. 미평가는 곧바로 빈 입력 폼으로 진입하며 점수 범위는 1~100이다.
- 변경: 성공적으로 조회한 미평가는 6개 점수·오버롤 0의 육각형 그래프를 기본 표시한다. 저장 데이터의 점수는 그대로 표시한다. 모든 입력은 명시적인 능력치 수정 버튼 뒤에서만 가능하다.
- 0~100 정수를 허용하며 입력에서 빈 항목은 0으로 저장한다. 미평가 조회만으로 DB 행을 생성하거나 팀 평균에 0점을 넣지는 않는다. 운영진이 저장한 0점은 실제 평가 행으로 구분한다.
- 조회 오류·로딩·권한 제외는 0점으로 오인하지 않도록 기존 별도 상태를 유지한다.
- 범위: 기존 능력치 패널·클라이언트 검증·관련 회귀 검사와 DB 점수 하한 확대. 기존 점수·평가 이력·권한·CAS·평균 정의는 유지한다.
- 앱: 웹 우선 정책에 따라 구현·검사·배포 대상에서 제외한다.
- 완료: 미평가/저장된 0점/기존 양수 점수 기본 그래프, 수정·취소·저장 흐름, 0점 서버 저장과 기존 거부 조건 확인, 독립 리뷰·웹 검사·DB 마이그레이션·PR 병합·운영 배포 확인.
