- Chrome 콘솔 warning/error: 0건

## 보류 및 운영 확인 항목

- Google/Kakao OAuth는 공급자 실계정과 동의 화면이 필요한 항목이라 이번 자동 테스트에서는 재로그인하지 않았다. 이메일 로그인과 기존 콜백 경로는 정상이다.
- PKCE 인증을 중간에 여러 번 취소할 때 생기는 임시 쿠키 누적은 기능 장애가 확인되지 않아 라이브러리 기본 정리 정책을 유지했다.
- 다크 모드는 현재 브랜드 디자인 범위에 포함하지 않았다.
- Supabase 보안 검사에는 공개 회원 디렉터리가 `SECURITY DEFINER` 함수라는 경고가 남는다. 함수는 인자 없이 고정된 비민감 열만 반환하고 `PUBLIC` 실행 권한을 회수한 뒤 `anon`, `authenticated`에만 명시적으로 허용했다.
- 유출 비밀번호 차단 기능은 Supabase 대시보드의 Auth 설정에서 별도 활성화가 필요하다.
