## 목적

로그인하지 않은 방문자 홈(`components/clubhouse.tsx`의 `Home`)의 큰 슬로건 `h1`('우리의 주말, / 우리의 풋살.')을 시안 A의 모션으로 바꾼다.
- 코트 라인이 그려진다.
- 공이 로브로 날아와 둘째 줄 밑을 굴러가며, 지나가는 자리마다 글자가 떠오른다.
- 공은 마침표 자리에 멈춰 마침표가 된다.

## 범위

- 포함: 모션 컴포넌트, 히어로 CSS, 줄인 모션·화면 밖·탭 숨김 처리, 테스트, 업데이트 노트
- 제외: 로그인 회원 홈(매치 콘솔), 오른쪽 다음 일정 패널, 레이아웃 셸, 데이터·인증
- 미정: 오른쪽 패널의 'WEEKLY SAT / SUN' 문구(실제 정기 경기는 일요일)는 사용자 답변 전이라 바꾸지 않는다.

## 완료 기준

- 모션: 약 4초 동안 한 번 재생하고 멈춘다(루프 없음). 화면 밖이거나 탭이 숨겨지면 일시 정지하고, 돌아오면 이어서 재생한다.
- `prefers-reduced-motion: reduce`이면 완성된 정지 화면을 바로 보여 준다.
- 스크린 리더와 SEO에는 슬로건 문구가 `h1`으로 그대로 남고, 모션 영역은 `aria-hidden`이다.
- 라이트·다크 × 1440·390px에서 가로 넘침이 없고, 첫 화면(스크롤 전)에 CTA가 보인다.
