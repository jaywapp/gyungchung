# 믹스트존 분석

2026-10-07 사용자 지시로 전체 구현·웹 운영 배포·모바일 웹 변경 동기화·Android 빌드와 발행을 진행한다. 이전 설계 질문의 권장안을 기본 정책으로 채택한다.

## 요구와 범위

지난 일정에 실제 참석한 회원이 함께 참석한 다른 구성원의 플레이를 평가한다. 기능명은 믹스트존이다. 운영진의 수동 능력치 입력 대신 참가자의 평가 집계가 회원 육각형 그래프와 팀 밸런스 참고 오버롤의 원천이 된다.

- 같은 일정의 출석·지각 회원을 평가하며 본인·미참석·비활동·테스트 계정·용병은 제외한다. 평가자는 인증 연결된 활동 회원이며 비밀번호 변경을 완료해야 한다.
- 6개 항목(속도·슈팅·패스·드리블·수비·피지컬)을 각각 1~5점으로 모두 선택한 대상만 제출한다. 전원 평가를 강제하지 않는다.
- 일정 종료 후 기본 3일, 운영진의 일정 관리 권한으로 1~30일을 설정한다. 종료 시각이 없으면 시작 2시간 후를 기준으로 한다. POTM 기간은 별도다.
- 원본은 작성자만 조회하고 마감 전 수정한다. 운영진에게는 집계만 제공한다. 회원 전체에게 오버롤을 공개하지 않는다.
- 기존 수동 점수와 감사 이력을 삭제하지 않는다. 수동 저장 RPC는 서버에서 거절하며 새 집계의 원천으로 사용하지 않는다.

## 집계 결정과 근거

대상별 평가가 존재하는 최근 10개 일정에서 항목별 응답 평균을 구한 뒤 일정 평균을 동일 가중치로 평균한다. 1~5점을 20배 하여 0~100 그래프에 반올림 표시한다. 많은 참가자가 있는 일정 하나가 전체를 압도하지 않도록 일정별 비중을 같게 한다. 평가 응답 수와 평가 일정 수를 함께 표시해 표본을 판단할 수 있게 한다. 표본이 없는 회원은 0 그래프를 표시하지만 팀 평균에서 제외한다. 저장된 평가가 즉시 집계에 반영되므로 마감 전 결과는 바뀔 수 있다. 이전 유효 응답을 이후 출석 수정으로 조용히 제거하지 않는다.
