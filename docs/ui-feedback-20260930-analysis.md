## 요청과 현재 상태

| 4 | 업데이트 노트에 직접 요청 작업도 올리고 출처 배지로 구분 | 노트는 `lib/update-notes.ts` 정적 배열이다(PR #163에서 수기 작성). 자동 수집 경로와 출처 필드가 없어서, PR이 노트를 추가하지 않으면 아무것도 올라가지 않는다. `/updates`는 `note.date`를 key로 써서 같은 날짜 노트 2개가 key 중복 경고를 낸다. |

## 범위 밖

- DB 트리거의 회비 금액(서버 측 기준값)은 그대로 둔다. 금액을 바꿀 때는 `lib/fee-rules.ts`와 마이그레이션을 함께 바꿔야 한다.
- DB에 저장된 답변 텍스트는 수정하지 않는다.
- 노트 자동 생성(GitHub 연동, DB 관리 화면)은 하지 않는다.
