# 계정 프로필 사진 분석

사용자 요청: 계정 프로필 이미지를 넣을 수 있도록 한다.

현재 웹·모바일은 공용 회원 아바타에 이름 이니셜을 표시하며 계정 화면에 사진 입력이 없다. profiles에는 사진 경로가 없고 운영 Storage bucket도 없다. 기존 로그인·회원 디렉터리·계정 보호 정책을 유지하면서 작은 계정 화면 확장으로 처리한다.

수용 기준:
- 마이페이지에서 본인 사진 등록·교체·삭제가 가능하고 기존 공용 아바타에 반영된다.
- 사진이 없거나 읽기가 실패하면 이니셜을 표시한다.
- 활동 중인 로그인 회원끼리 현재 사진을 조회하며, 변경은 본인만 가능하다.
- 실패·취소·동시 변경·계정 전환 때 기존 사진과 새 계정 상태를 보호한다.
- 웹과 이전 설치 앱의 API 호환성 및 기존 초기 DB 요청 수를 유지한다.

범위는 계정 사진과 필요한 공유 Storage/RPC다. 역할·회비·연락처 접근 정책, 참고 서브모듈, 주요 탐색·디자인 시스템은 이번 작업에서 변경하지 않는다. 실제 회원의 데이터나 사진으로 쓰기 검증하지 않는다.
