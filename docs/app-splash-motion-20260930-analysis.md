# 앱 스플래시 모션 — 분석

## 목적

홈 화면에 설치한 경충FC 웹앱(PWA)을 열 때, 브랜드를 알리는 짧은 시작 모션을 보여 준다. 같은 모션을 이후 Expo 앱(`docs/mobile-app-design.md`)에서도 재사용한다.

## 결정 사항 (2026-09-30, 사용자)

- 시안 A '킥오프 궤적'을 쓴다(`docs/ux-concepts/app-splash-motion-20260930/`).
- 워드마크는 `경충FC`가 아닌 `GCFC`다. 네 글자 모두 채운 글자이고 F만 라임색(`--highlight`)이다.
- 홈 화면 아이콘은 남색 바탕에 GCFC 워드마크와 라임 공 마침표를 쓴다.
- 설치 후 첫 실행에만 전체 모션(약 1.8초)을 재생하고, 이후 실행에는 완성 화면을 짧게 보여 주고 넘긴다.
- 이번 범위는 웹앱이다. Expo 앱은 앱 작업을 시작할 때 공용 모듈(`lib/splash-motion.ts`)을 가져다 쓴다.

## 시나리오

1. 회원이 브라우저에서 '홈 화면에 추가'로 설치한다(manifest 필요).
2. 홈 화면 아이콘으로 처음 열면 남색 화면에서 공이 날아와 GCFC 밑을 굴러가며 글자를 띄우고, 마침표 자리에 멈춘다. 이어 `WEEKEND FUTSAL CLUB · EST. 2018` 문구가 나오고 앱이 드러난다.
3. 두 번째부터는 완성된 워드마크를 약 0.4초 보여 주고 넘긴다.
4. 화면을 탭하면 즉시 건너뛴다.
5. 브라우저 탭으로 여는 일반 방문에는 나오지 않는다.

## 범위

- 포함: 웹앱 manifest와 아이콘, 시작 모션 오버레이, 공용 좌표·타이밍 모듈과 테스트, 업데이트 노트
- 제외: Expo 앱 구현, 서비스 워커·오프라인, iOS 기기별 시작 이미지(`apple-touch-startup-image`), 기존 파비콘 교체

## 완료 기준

- manifest가 `display: standalone`, 남색 배경, 192·512px 아이콘(maskable 포함)을 제공한다.
- 설치 실행에서만 오버레이가 나오며, 첫 실행과 이후 실행이 구분된다. `?splash=preview`로 브라우저에서도 확인할 수 있다.
- 움직임 줄이기 설정에서는 이동 모션 없이 완성 화면만 짧게 보여 준다.
- 스크립트가 실패해도 4초 뒤에는 오버레이가 사라진다.
- lint, 타입 검사, 테스트, 빌드가 통과한다.
