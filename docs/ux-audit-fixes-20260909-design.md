# UX/UI 점검 보완 설계

orchestrator: Codex

## 구조와 흐름
- 홈 참석 패널은 publicLoading → eventLoadError → upcoming 여부 순으로 렌더링한다.
- 회비 패널은 sessionPending → 로그인 여부 → 회비/프로필 오류 → 내역 여부 순서로 표시한다. 회원 데이터 재시도를 별도로 제공한다.
- 계정 미연결 모달은 불가능한 의견 작성 링크를 제거한다. 의견 화면을 직접 연 미연결 사용자에게도 같은 등록 안내를 제공한다.
- 일정 관리 메뉴는 첫 항목/마지막 항목 진입, 방향키·Home·End 순환, Escape 포커스 복원을 지원한다.
- 모바일 홈 제목은 2줄이 유지되도록 반응형 글자 크기를 줄이고 상하 여백을 축소한다. 문구와 정보 순서를 보존한다.

## 대안과 검증
- 문의 제출 권한 확대는 인증 정책 변경이므로 제외한다. 운영진 연락처는 근거가 없어 임의 추가하지 않는다.
- 메뉴를 일반 버튼 그룹으로 바꾸는 대안보다 기존 ARIA 메뉴 패턴을 완성한다.
- 기존 테스트, 상태 렌더링 회귀 검사, lint, 프로덕션 빌드를 실행한다.
- 로컬 브라우저에서 데스크톱·390px·320px, 오류/로딩 상태, 로그인·메뉴 동작을 확인한다. 실제 계정이 필요한 흐름의 미검증 범위를 구분한다.
