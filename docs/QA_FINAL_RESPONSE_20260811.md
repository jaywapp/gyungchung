## GitHub 제보 연동 조치

- 사용자 의견은 기본적으로 팀 내부 DB에만 저장한다.
- 작성자가 체크박스로 공개 등록에 동의한 경우에만 제목과 본문을 공개 GitHub Issue로 전송한다.
- 이름, 이메일, 전화번호, 사용자 ID 등 작성자 개인정보는 이슈 본문에 포함하지 않는다.
- Supabase Edge Function에서 로그인 사용자와 제보 소유권을 재검증한다.
- 시간당 공개 제보를 5건으로 제한하고, 생성된 Issue 번호와 URL을 원본 제보에 저장한다.
- 실패 시 내부 제보는 보존하고 작성자가 GitHub 연결만 다시 시도할 수 있다.
- 운영진 화면에서 연결 상태와 Issue 링크를 확인할 수 있다.
- GitHub `제보` 라벨을 생성해 앱에서 등록된 이슈를 구분한다.
