# 경충FC 웰컴 페이지 기획과 요구사항

신규 회원에게 안내 링크 하나를 전달하면 회칙과 운영진을 확인하고 앱을 설치할 수 있는 공개 페이지를 만든다. 운영진은 기존 관리 화면에서 내용을 수정하고 게시한다. Android 설치는 이미 운영 중인 공개 APK 배포를 활용한다.

- 작성일: 2026-10-02, Asia/Seoul
- 대상 URL: https://gyungchung.vercel.app/welcome
- 상태: 기획 초안. 공개 시안은 2026-10-02에 03 구단 소개형으로 선택됐다. 미정 콘텐츠·권한 확정과 제품 구현은 후속 단계다.
- 문서 독자: 운영진, 디자이너, 웹·앱 개발 담당자
- 관련 문서: [설계](welcome-page-design.md), [실행 계획](welcome-page-tasks.md), [페이지 시안 요청서](welcome-page-design-request.md)

## 목표와 완료 기준

방문자는 로그인 없이 페이지 전체를 읽고 Android 설치 파일을 받는다. 운영진은 개발자 도움 없이 안내 문구·회칙·공개 소개·iOS 배포 상태를 수정한다. 내용 게시에 웹 재배포가 필요하지 않아야 한다.

| 사용자 | 해야 할 일 | 완료 기준 |
| --- | --- | --- |
| 신규 회원 | 회칙과 이용 절차 이해, 앱 설치 | 공개 링크에서 필요한 정보를 찾고 설치로 이동한다 |
| iPhone 사용자 | iOS 준비 상태와 대체 경로 확인 | 준비 중인 버튼을 다운로드로 오인하지 않고 웹으로 이용한다 |
| 운영진 | 내용을 수정하고 공개 결과 확인 | 초안을 저장·미리보기·게시하고 게시 상태를 확인한다 |
| 기존 회원 | 회칙 재확인, 최신 앱 확인 | 기존 로그인과 회원 기능이 영향을 받지 않는다 |

## 사용자 요청과 확인된 사실

사용자는 공개 /welcome, 회칙, 운영진 소개, Android 및 향후 iOS 다운로드, 운영진 관리 메뉴를 요청했다. 세 저장소를 함께 살펴본 뒤 기획 문서와 시안 요청서를 만들도록 지시했다.

2026-10-02 조사 기준이다. 릴리스 버전은 조사 시점의 사실이며 구현 시 다시 확인한다.

| 저장소 | 확인한 역할 | 이번 계획에서의 책임 |
| --- | --- | --- |
| gyungchung | Next.js 웹, Supabase 데이터·권한·서버 함수 | 공개 페이지, 편집 메뉴, 게시 처리, 다운로드 정보 연결 |
| gyungchung-mobile | 비공개 Expo/React Native 앱, APK 빌드·서명·배포 | 기존 배포·업데이트 계약과 브랜드 자료 제공 |
| gyungchung-releases | 공개 APK·update.json·checksums.sha256 | 비로그인 첫 설치 파일과 공개 버전 정보 제공 |

- 웹 조사 기준 main은 41b5bfd6eafdbfa916db796e221b78f5753bc0a5다. 이전 로컬 작업 브랜치 대신 이 기준의 메뉴·테마·모바일 API를 사용한다.
- 모바일 조사 기준 main은 1f9d320c199a8da0d116d5c42b969a28dd0c8422다. 모바일 문서에는 이전 검증 시점의 기록도 있으므로 실제 릴리스·CI 결과와 구분한다.
- 공개 최신 릴리스는 android-v0.1.0-build.10, versionName 0.1.0, versionCode 200010, APK 크기 85,611,780 bytes다.
- Android 배포 워크플로 실행 10의 성공, 공개 update.json의 익명 GET 200 및 최신 APK의 익명 HEAD 200을 확인했다. 이번 조사는 APK 전체 다운로드·실기기 설치 검증을 포함하지 않는다.
- 기존 mobile-updates의 버전 정보 GET은 비로그인으로 조회할 수 있다. 앱 내 APK 스트리밍은 연결된 active/pending 회원 인증을 요구한다.
- 웹과 앱은 운영진이 발급하는 전화번호·비밀번호 계정을 공유한다. 공개 회원가입·문자 OTP·소셜 로그인은 제공하지 않는다.
- iOS의 기존 계획은 Android 실사용 완료 후 같은 소스로 TestFlight·심사·미등록 앱 링크 배포를 진행하는 것이다. 현재 사용 가능한 iOS 배포 링크는 확인하지 않았다.
- 기존 회원 정보에는 전화번호·이메일·계정 연결 및 권한 정보가 포함된다. 공개 운영진 소개는 별도 공개 콘텐츠로 관리한다.

## 첫 제공 범위

| 영역 | 요구사항 | 관리 범위 |
| --- | --- | --- |
| 환영 안내 | 짧은 소개와 회칙·앱 설치 바로가기 | 제목·소개 문구 |
| 이용 시작 안내 | 계정 등록 요청, 첫 로그인, 비밀번호 변경 안내 | 단계별 문구 |
| 회칙 | 웹에서 읽는 전문, 목차, 시행일·개정일 | 제목·본문·날짜 |
| 운영진 | 이름·직책·소개, 사진이 없어도 성립하는 구성 | 추가·수정·삭제·순서·선택 사진 |
| Android | APK 다운로드, 설치 안내, 버전·크기·변경사항 | 노출·설치 안내는 편집, 배포 정보는 자동 조회 |
| iOS | 준비 중·테스트 배포·정식 배포·숨김 | 상태·안내·확인된 배포 링크 |
| 관리 | 초안 저장, 권한 있는 미리보기, 게시 | 기존 관리의 운영 그룹에 웰컴 페이지 메뉴 추가 |

다음은 구현 제안이며 사용자 답변으로 조정할 수 있다.

- 운영진 소개는 공개 이름·직책 표시명·소개글을 기본으로 하고 사진은 선택한다. 개인 연락처는 초기 공개 필드에 포함하지 않는다.
- 회칙 원문은 웹 본문을 기준으로 한다. PDF 첨부와 사진 직접 업로드는 자료·필요를 확인한 후 추가한다. 첫 버전의 선택 사진은 승인된 공개 이미지 주소 또는 기존 프로젝트 자산을 사용한다.
- welcome.manage 권한 하나를 추가한다. 회장과 시스템 관리자에게 초기 관리 권한을 주고 기존 방식으로 부회장·총무에게 위임하는 안이다.
- 회칙 동의 수집, 다단계 결재, 임원 이력, 범용 페이지 빌더, 앱 자체 개발 및 새로운 APK 저장소 구축은 첫 범위에 포함하지 않는다.
- 기존 홈 주소와 로그인 흐름은 유지한다. 웰컴 페이지 진입 링크를 기존 웹의 어디에 둘지는 시안에서 제안한다.

## 운영 원칙

콘텐츠는 임시 저장 → 미리보기 → 게시로 반영한다. 편집 중에는 기존 게시본을 유지하고 여러 항목을 한 번에 게시한다. 수정자·수정 시각·게시 시각과 미게시 변경 여부를 운영진에게 보여 준다.

Android 버전은 운영진이 수동 입력하지 않는다. 공개 콘텐츠 게시와 앱의 새 릴리스 공개는 서로 다른 작업이다. 새로운 검증 릴리스의 버전·파일 정보는 자동 갱신하며, 운영진이 작성한 회칙과 안내는 게시 동작으로만 바뀐다.

회원용 비공개 데이터와 초안은 공개 응답에 포함하지 않는다. 운영진 소개 편집이 실제 회원 직책·계정 권한 변경으로 이어지지 않게 한다.

## 미정 사항과 제안 기본값

| 항목 | 현재 상태 | 문서와 시안에서 사용할 기준 | 확정 시점 |
| --- | --- | --- | --- |
| 회칙 원문과 시행일 | 자료 미제공 | 시안에는 실제 회칙이 아닌 예시임을 명시 | 최초 게시 전 |
| 실제 운영진 소개 | 명단·문구·사진 미제공 | 공개용 자리표시자, 개인 연락처 제외 | 최초 게시 전 |
| 초기 편집 담당 | 직접 답변 없음 | 회장·시스템 관리자 기본, 위임 가능 제안 | 권한 적용 전 |
| 검색엔진 노출 | 미정 | 공개 접근과 검색 노출은 별개. 시안에 영향 없음 | 메타데이터 확정 전 |
| iOS 배포 링크 | 미제공 | 출시 준비 중과 웹 이용 안내 | 실제 iOS 전환 전 |
| 디자인 | 03 구단 소개형 선택(2026-10-02), 추가 피드백 없음 | [시안 03](ux-concepts/welcome-page/concept-03/)과 [관리자 공통안](ux-concepts/welcome-page/admin/) | 확정 |

기존 Android 배포 방식은 저장소와 실제 공개 릴리스로 확인했으므로 다시 질문할 필요가 없다. 미정 콘텐츠는 기획 문서와 시안 요청서 작성의 장애가 아니며, 운영 원문으로 임의 확정하지 않는다.
