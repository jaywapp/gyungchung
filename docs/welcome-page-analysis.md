# 경충FC 웰컴 페이지 기획과 요구사항

신규 회원에게 공개 안내 링크 하나를 전달한다. 운영진 소개, 필수 앱 설치, 계정 이용 순서를 간단히 안내하고 운영진이 기존 관리 메뉴에서 내용을 수정·게시한다.

- 작성·최종 결정일: 2026-10-02, Asia/Seoul
- 대상 URL: https://gyungchung.vercel.app/welcome
- 상태: 로컬 구현과 검증 진행. 운영 DB 반영·원격 푸시·배포는 별도 요청 후 진행한다.
- 관련 문서: [설계](welcome-page-design.md), [실행 계획](welcome-page-tasks.md), [시안 요청서](welcome-page-design-request.md), [검증 기록](welcome-page-verification.md)

| 회칙 | 신규 회원이 간단히 파악하도록 공개 페이지·관리 편집·콘텐츠 구조에서 제외 |

최초 요청에는 회칙이 있었으나 사용자가 구현 중 제외하도록 정정했다. 기존 시안은 시각적 기준으로 보존하고 위 결정을 제품의 최신 기준으로 적용한다. 별도의 회칙 페이지나 회칙 관리 기능은 추가하지 않는다.

## 세 프로젝트 조사 결과

2026-10-02 확인한 저장소의 역할이다. 릴리스 버전은 조사 시점의 값이며 제품에 고정하지 않는다.

| 저장소 | 역할 | 이번 구현의 책임 |
| --- | --- | --- |
| gyungchung | Next.js 웹, Supabase 데이터·권한·서버 함수 | 공개 페이지, 기존 관리 메뉴의 편집기, 게시 처리, 다운로드 정보 연결 |
| gyungchung-mobile | Expo/React Native 앱, APK 빌드·서명·배포 | 기존 업데이트 응답 파서의 추가 필드 호환 확인 |
| gyungchung-releases | 공개 APK·update.json·checksums.sha256 | 비로그인 첫 설치 파일과 버전 정보 제공 |

- 최초 조사 당시 Android 배포는 `android-v0.1.0-build.10`, 버전 `0.1.0`, 코드 `200010`이었다. 구현 검증 중에는 코드 `200011`의 새 릴리스를 자동 조회했다.
- 공개 APK와 update.json은 익명으로 접근 가능하다. 기존 앱 내 APK 스트리밍은 연결된 활동·승인 대기 회원 인증을 요구한다.
- 웹과 앱은 운영진이 발급한 전화번호·비밀번호 계정을 공유한다. 공개 회원가입·문자 OTP·소셜 로그인을 추가하지 않는다.
- 초기 비밀번호는 첫 로그인 뒤 변경해야 한다. 안내 문구도 실제 계정 프로비저닝 흐름을 따른다.
- 현재 사용할 iOS 배포 링크는 제공되지 않았다. TestFlight·App Store 전환을 위한 편집 필드를 준비한다.
- 공개 운영진 소개는 회원 디렉터리와 분리한다. 전화번호·이메일·인증 계정·권한 정보를 공개 필드에 포함하지 않는다.

사진 업로드·개인 연락처·임의 HTML·범용 페이지 빌더·공개 회원가입은 포함하지 않는다. 앱 설치 필수 안내를 제공하고 기존 웹 이용 경로도 유지한다. iOS 출시 전에는 사용할 수 없는 설치 버튼을 만들지 않는다.

## 운영 원칙

초안 저장은 공개 내용에 영향을 주지 않는다. 게시하면 저장한 초안 전체를 한 번에 공개하고 다음 방문 요청부터 새 게시본을 조회한다. 수정·게시 시각과 미게시 변경 상태를 표시한다.

저장·게시 실패, 다른 운영진과의 충돌, 권한 회수 때 작성한 입력을 유지한다. 충돌을 자동으로 덮어쓰지 않고 최신 초안 비교·내용 복사·명시적 변경 폐기를 제공한다. 메뉴 이동·주요 페이지 이동·새로고침 시 미저장 이탈을 확인한다.

Android의 버전 정보와 APK 주소는 같은 검증 릴리스에서 선택한다. 새 APK 공개와 콘텐츠 게시를 구분하고 다운로드 정보 갱신에 콘텐츠 재게시를 요구하지 않는다. 조회 실패 시 버전 수치는 숨기고 공식 공개 최신 파일 주소와 재시도를 제공한다.

## 운영 반영 전에 필요한 것

실제 운영진 공개 자료는 첫 게시 전에 운영진이 등록한다. iOS 배포 주소는 실제 배포 시점에 등록한다. 가상 인물을 게시하거나 존재하지 않는 iOS 배포를 표시하지 않는다.

운영 DB에 마이그레이션을 적용·검증한 뒤 웹을 배포해야 한다. 원격 권한 검사, 실제 게시 흐름, APK 실기기 설치, iOS 배포 연결은 운영 반영 시 확인한다. 로컬 검증 범위와 제한은 [검증 기록](welcome-page-verification.md)에 남긴다.
