`effort`는 상대 규모(M/L)이며 일정 약속이 아니다. `parallel_group`은 병렬 가능한 업무의 후보다. 공유 셸·토큰·스키마 변경은 순차 처리한다. 모델 표기는 역할 계획이며 실제 수행 모델은 착수 시 사용 가능한 설정에 맞춘다.

M09·M10은 D01·D06·D07 결정 후 선택한다. 포함한다면 M11·M13의 선행 작업에 해당 ID를 추가한다. 제외한다면 앱 화면·메뉴·심사 자료에서 해당 기능을 제거한 상태로 검증한다. 개인정보 정책 등 운영 의사결정과 기술 검증은 분리하여 진행할 수 있다.

## 첫 기술 마일스톤

M03~M06 완료 시 같은 소스에서 두 OS를 빌드하고, 실기기에서 로그인 → 필요한 초기 비밀번호 변경 → 매치 콘솔 참석 응답 → 일정 상세 → 앱 재시작 후 세션 복원을 확인한다. 하단 탭과 세 가지 테마가 동작하고 기존 웹 검사·빌드도 통과해야 한다.

## 출시 게이트

- **범위:** D01~D08의 출시 관련 결정 완료. 포함되지 않은 기능의 진입점과 미완성 화면이 없음.
- **기능·접근성:** 홈 모듈과 목적지, 목록·상세·뒤로가기·키보드, 상태·오류·오프라인, 테마·글자 확대·스크린리더를 양 OS에서 확인.
- **데이터·권한:** 서울 날짜·마감·시즌 집계 일치. 역할별 읽기·쓰기 제한, 세션 종료 후 캐시 제거, 심사 데이터 격리 확인.
- **심사:** 공개 의견 포함 시 관리 기능 완료. 개인정보·지원·계정 처리·시연 계정·스크린샷·심사 메모 준비.
- **배포:** APK 설치·업데이트 및 iOS 앱 심사·미등록 승인·링크 설치 완료. 서명 키·계정·장애·버전 안내 담당자 인계.

## 이번 갱신의 검증 기록

이 절에는 문서 갱신 후 실행한 검사 결과를 기록한다. 앱 빌드·실기기·App Review 검증은 모바일 구현 단계의 별도 작업이며 현재 완료되지 않았다.

- 문서 상대 링크: 모두 존재 확인.
- `npm test`: 123개 통과.
- `npm run lint`: 통과.
- `npm run build`: 통과(정적 페이지 19개 생성).
- `npx tsc --noEmit`: 빌드 완료 후 단독 실행 통과. 최초 병렬 실행에서는 `.next/types` 재생성과 충돌하여 재실행함.
- 변경 범위: 모바일 기획서 세 파일과 문서 목록. 앱 코드·스키마 변경 없음.
