# 회원 카드 동작 메뉴 분석
작성일: 2026-10-06 · orchestrator: Codex

요청: 카드에 전화걸기 버튼을 상시 노출하지 않고 카드 선택 시 여러 메뉴를 열어 전화걸기를 포함한다. 연락처 저장도 추가한다. 사용자 지시로 이번 묶음은 로컬 구현만 준비하고 전체 테스트·빌드·배포는 나중에 진행한다. 커밋·push·PR·병합도 이번 범위에 포함하지 않는다.

현재 웹은 회원 상세 보기와 카드·상세의 전화 동작, 관리자 메뉴가 나뉜다. 최신 main의 회원 상세 기능을 유지한다. 모바일은 카드의 전화 버튼과 운영진용 Sheet가 있다. 명단의 전화번호는 미리 조회하지 않고 get_member_phone RPC로 선택한 한 명만 읽는다.

완료 기준: 카드 전체가 클릭/키보드 또는 터치 대상이며 일반 활동 회원도 전화/저장 메뉴를 사용할 수 있다. 카드 밖에는 전화 버튼이 없다. 본인 및 시스템 관리자 강퇴 차단과 members.manage 조건을 유지한다. 계정 전환/권한·활동 상태 변경/메뉴 닫기 뒤 늦은 연락처 결과는 폐기한다. 이름·전화번호만 저장 대상으로 전달한다.

서버 스키마·RLS·운영 회원 데이터는 바꾸지 않는다. 저장은 사용자 확인 흐름으로 준비하며 기기 주소록 읽기·자동 일괄 저장은 구현하지 않는다. 기존 디자인의 좁은 상호작용 개선으로 콘셉트/탐색/색/글꼴을 교체하지 않는다.

## 웹 우선 진행
2026-10-06 후속 사용자 지시로 웹 검사·빌드·배포를 먼저 수행한다. 사용자가 배포된 웹을 점검하고 동기화를 요청한 뒤 모바일을 진행한다. 앞선 보류 내용은 최초 로컬 준비 범위를 뜻하며 현재 웹 검증은 member-card-actions-validation.md에 기록한다.
