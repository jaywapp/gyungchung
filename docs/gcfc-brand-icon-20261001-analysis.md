# GCFC 아이콘·가로 로고 — 분석

## 목적

앱 스플래시의 GCFC 워드마크를 기준으로 클럽 아이콘과 가로 로고를 정해, 웹사이트와 이후 Expo 앱에서 같은 자산을 쓴다.

## 결정 사항 (사용자, 2026-10-01)

- 아이콘은 시안 B(GC / FC 2단)다(`docs/ux-concepts/app-icon-20261001/`).
- 가로 로고는 스플래시 끝 장면(GCFC 워드마크, 공 마침표, `WEEKEND FUTSAL CLUB · EST. 2018`)을 바탕으로, 어두운 배경용과 밝은 배경용 두 가지를 만든다.

## 범위

- 포함
  - 파비콘(`app/icon.png`), iOS 아이콘(`app/apple-icon.png`), 웹앱 아이콘 3종 교체
  - 가로 로고 SVG·PNG를 `public/brand/`에 추가
- 제외
  - 화면 안의 로고(사이드바·상단 바의 GC 배지)와 공유 이미지(`og.png`) 교체
  - Expo 앱 적용. 앱용 원본은 `gyungchung-mobile`의 작업 폴더에 둔다.

## 완료 기준

- 아이콘과 로고는 글자를 윤곽선으로 바꾼 SVG가 원본이어서, 서체가 없는 환경에서도 똑같이 보인다.
- 밝은 배경용 로고는 라임 대신 브랜드 녹색(`#157a43`)을 써서 흰 바탕에서도 대비가 유지된다.
- lint, 타입 검사, 테스트, 빌드가 통과한다.
