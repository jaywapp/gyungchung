# iPhone 홈 화면 앱 제공 분석

## 확정 요구사항

- 유료 Apple Developer 계정 없이 팀원에게 기존 클럽하우스 기능과 푸시 알림을 제공한다.
- iPhone에서는 Safari에서 홈 화면에 추가하고, 홈 화면 앱에서 로그인 후 알림을 켠다.
- iOS 16.4 이상을 지원하며 앱이 화면에 열려 있지 않아도 서버에서 알림을 보낸다.
- 기존 Android 앱과 Expo 알림은 유지한다. 모바일의 TestFlight 준비 브랜치는 별도로 보관한다.
- 기존 회원 계정, 업무 알림 종류, 수신 대상과 개인 설정을 재사용한다.

## 범위와 완료 기준

1. 기존 `/welcome`의 설치 안내에서 iPhone 이용 방법을 찾을 수 있다.
2. 로그인한 회원이 계정 화면에서 현재 기기의 알림 등록, 해제, 종류별 설정과 본인 대상 테스트를 수행한다.
3. 서버가 업무 이벤트를 웹 구독에도 전달하고, 만료 구독과 일시 오류를 구분한다.
4. 알림 선택 시 안전한 클럽하우스 경로를 열며 로그아웃 및 계정 변경 시 이전 계정의 구독을 차단한다.
5. 관련 검사와 프로덕션 빌드, 운영 스키마/함수/웹 배포 및 응답을 검증한다.
6. 실제 iPhone의 홈 화면 설치, 닫힌 상태 수신, 알림 선택 이동은 실제 기기 확인 결과를 별도로 기록한다.

## 기존 상태

- 시작 기준: `origin/main`의 `2d47049`.
- manifest, iOS 홈 화면 아이콘, standalone 표시와 테마가 이미 구성되어 있다.
- 기존 푸시 설치/전송 테이블은 Expo 전용 계약이므로 웹 구독을 별도로 관리한다.
- `/welcome`은 이미 승인된 `03 구단 소개형` 콘셉트를 사용한다. 설치 영역과 계정 모달에 한정해 확장하며 새로운 화면 콘셉트나 탐색 체계를 만들지 않는다.
- iOS 알림은 홈 화면 설치와 사용자의 버튼 선택에 따른 권한 요청이 필요하다. Apple Developer 유료 가입은 필요하지 않다.

## 제외

App Store/TestFlight 배포, 오프라인 개인정보 캐시, 네이티브 기능 추가와 Android 릴리스 변경은 포함하지 않는다.
