# 총무 회비 저장 오류 분석

- 제보일: 2026-10-05. 제보 범위는 10월 4일 19~20시 KST 웹 회비 등록 실패다.
- 운영 로그: 19:48:08, 19:48:27, 19:48:33, 19:55:07에 SQLSTATE P0001 / `The member fee policy is not configured`가 기록됐다.
- 원인: 총무에게 `fees.manage`만 있고 `members.manage`는 없다. 회비 RLS는 저장을 허용하지만 invoker 표준 금액 트리거가 `profiles`를 직접 읽어 대상 회원의 role/fee_plan을 얻지 못한다.
- 연관 계약: 기존 회원 목록 RPC에는 fee_plan이 없어 회비 담당자의 참여비형 표시와 월회비 일괄 대상도 잘못 판단할 수 있다.
- 범위: 권한이 검증된 최소 회비 정책 조회와 기존 목록 RPC의 제한된 fee_plan 필드, 회귀 검증 및 업데이트 노트.
- 보존: 회원 연락처·계정 데이터 RLS, 표준 금액 15,000/30,000/10,000원, 숨김 계정, 기존 앱 응답 호환, 초기 조회 개수, 실제 회비 기록.
