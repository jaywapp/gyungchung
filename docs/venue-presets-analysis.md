# 주변 풋살장 프리셋 요구사항

## 목적과 범위

경기도 광주시·용인시·성남시의 공개 풋살장 정보를 DB에 쌓고, 운영진이 일정을 등록하거나 수정할 때 이름과 주소를 쉽게 선택한다. 광주광역시는 제외한다. 인접 도시는 추가 범위 확인 전에는 포함하지 않는다.

기존 웹·앱에는 `venues` 선택, 이름·주소 직접 입력, 직접 입력한 구장의 선택적 저장이 있다. 이를 이용하며 등록·수정 권한과 기존 일정의 장소 스냅샷을 유지한다.

## 완료 기준

- 아이엠그라운드의 현행 공개 목록과 지자체·시설 운영자·공개 예약 정보로 세 도시의 시설을 조사한다.
- 도시, 이름, 주소, 코트 구분, 공개 출처, 자료 확인 날짜를 저장한다. 확인할 수 있는 좌표는 함께 보존한다.
- 예약 구분이 있는 A/B 코트는 선택지로 구분한다. 이름 별칭·같은 코트의 플랫폼 중복은 합친다.
- 주소·풋살 용도가 불명확하거나 폐업·대관 중단이 확인된 후보는 프리셋에 확정 등록하지 않는다.
- 기존 세븐풋살장 ID를 유지하고 새 별칭이 동일 구장을 중복 생성하지 않게 한다.
- 대량 목록에서도 웹·앱 일정 작성의 검색과 직접 입력을 사용할 수 있다.
- DB 반영·재실행 시 중복 없음·기존 일정 참조 보존·권한·웹 운영 배포를 확인한다.

## 수집 한계

자료 확인 날짜는 현장 영업 확인 날짜와 다르다. 공개 예약 플랫폼의 검색 조건·날짜에 따라 목록이 달라질 수 있어 도시별·날짜별 조회 범위와 페이지 수를 기록한다. 여러 공식 출처를 보완해도 비공개 시설이나 최근 개폐업까지 포함하는 전수 보장을 하지 않는다.

사진·후기·홍보 설명은 복제하지 않는다. 구장명·주소·코트·공개 좌표 같은 장소 사실만 사용한다. 수집은 로그인 없는 공개 페이지에서 실제 사용하는 목록에 한정한다.
